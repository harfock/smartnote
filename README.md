# 智醒長者・自由空間數位照護日誌 (Smart Senior Care Digital Journal)

「智醒長者・自由空間數位照護日誌」是一款專為長者、家屬及照顧者設計的高互動性、無障礙數位照護管理系統。透過無限畫布（Infinite Canvas）的概念，使用者可以自由拖拽、組織與紀錄每日的叮囑事項、服藥提醒、生活待辦與溫馨家書。

---

## 🌟 主要功能特色

### 1. 自由畫布與排版系統 (Infinite Canvas & Layout)
* **平移與縮放**：支援自由拖拽畫布與 `40%` 至 `200%` 的無級縮放，適應不同尺寸的螢幕。
* **卡片拖拽與折疊**：所有叮囑卡片皆可任意拖動位置；支援一鍵「全部折疊」省空間模式與網格重設。
* **長者友善護眼模式**：提供一鍵切換「🌙 護眼」暖色調介面，降低視覺疲勞。

### 2. 多功能叮囑卡片 (Smart Care Cards)
* **多元內容格式**：支援設定主要標題、待辦事項清單（Checklist）、外部網址連結（如 YouTube 健康影片）與圖片網址預覽。
* **發起人與接收人標籤**：動態關聯成員檔案，清楚標示叮囑是「給誰 (To)」以及「來自誰 (From)」。
* **放大全螢幕檢視**：針對視力較弱的長者，提供一鍵「放大」巨型字體展示與「我看到了 (ACK)」確認按鈕。
* **動態太陽軌跡時鐘**：內建太陽升落視覺化弧線時鐘，以「早上 / 下午 / 晚上」簡單直觀的方式呈現時間。

### 3. 多重成員檔案與頭像編輯 (Profiles Manager)
* **客製化頭像裁切**：支援上傳相片，並提供實時**縮放、旋轉與拖拽中心點**的相片編輯器，精準擷取人臉頭像。
* **預設發起/接收對象**：可彈性設定預設叮囑對象，提升新增記錄時的效率。

### 4. 快捷貼紙與分類管理 (1-Tap Stickers & Categories)
* **一鍵快捷貼紙**：內建「記得飲水」、「返嚟食飯」、「天冷穿衣」、「量度血壓」等一鍵常用貼紙，支援自訂替換。
* **自訂主題分類**：提供食藥、覆診、家書、待辦、網頁等多種預設主題色彩，可自行擴充與修改名稱。

### 5. 每小時讚賞叮囑彈窗 (Hourly Praise Pop-Up)
* **主動溫馨關懷**：可設定定時（如每 60 分鐘）自動跳出關懷與讚賞語錄。
* **智慧睡眠暫停**：預設於夜間睡眠時間（22:00 - 08:00）自動暫停彈窗，不打擾長者休息。
* **語錄庫管理**：支援自行新增與刪除溫馨關懷詞庫。

### 6. 資料儲存與安全備份 (Save & Load System)
* **8 位數紀錄編號**：每次存檔均配有獨立編號（Record ID），方便分類與追蹤。
* **自動與手動備份**：支援瀏覽器 `LocalStorage` 自動保存（Auto-save）、手動 JSON 檔案下載以及自訂目標儲存資料夾。

## 🚀 快速開始 (Getting Started)

本專案採用**單一檔案無依賴架構 (Single-file Zero-dependency Architecture)**，無需安裝任何 Node.js、編譯工具或資料庫。

### 使用步驟：
1. 下載或複製本專案中的 `index.html` 檔案。
2. 直接使用任何現代網頁瀏覽器（如 Google Chrome, Safari, Microsoft Edge, Firefox）開啟 `index.html` 即可開始使用。
3. 可將網頁加入瀏覽器書籤或新增至行動裝置主畫面以獲得最佳體驗。

## 🛠️ 技術架構 (Technical Architecture)

* **前端語言**：HTML5, CSS3, JavaScript (Vanilla ES6+)
* ** UI/UX 設計**：自訂 CSS Variable 主題系統、Flexbox / Grid 彈性佈局、Pointer Events 畫布拖動技術
* **資料儲存**：Web Storage API (LocalStorage), File System Access API (資料夾選擇)
* **字型與視覺**：系統預設無障礙繁體中文黑體，配合高對比顏色標籤

---

## 📋 使用情境建議 (Use Cases)

1. **家庭照護紀錄**：子女遠端或每日為長者安排「食藥」、「量血壓」等定時叮囑。
2. **日間照顧中心**：工作人員紀錄長者每日活動、飲食與復健進度。
3. **長者自主生活管理**：大字體與太陽軌跡時鐘協助時間感知，完成待辦事項後可點選打勾與確認。
